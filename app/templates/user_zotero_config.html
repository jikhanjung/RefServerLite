    Setup Instructions
    Getting Your User ID:
    1. Go to zotero.org
    2. Log in to your account
    3. Click on your username in the top right
    4. Your User ID is the number in the URL
    Creating an API Key:
    1. Go to API Keys settings
    2. Click "Create new private key"
    3. Set appropriate permissions
    4. Copy the generated key
    Permissions needed: Your API key should have "Allow library access" and "Allow write access" permissions for full functionality.
