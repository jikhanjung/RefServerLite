# 사용자 및 관리자 기능 대폭 강화, v0.1.5 업데이트

**날짜:** 2025-07-22

## 작업 개요

v0.1.5 업데이트를 통해 사용자 시스템을 완성하고, 관리자 패널을 전면 개편했으며, Zotero 연동 및 중복 문서 관리 기능을 대폭 강화했습니다. 이번 업데이트는 단순한 기능 추가를 넘어, 시스템의 사용성, 보안, 확장성을 크게 향상시키는 데 중점을 두었습니다.

## 주요 변경 사항

### 1. 사용자 및 관리자 기능

- **관리자 페이지 전면 개편**:
  - 기존의 단일 페이지 구조에서 벗어나, 사이드바 기반의 현대적인 대시보드 UI를 도입했습니다.
  - 이제 각 기능(사용자 관리, 문서 관리, Zotero, 시스템 작업 등)은 별도의 하위 페이지에서 관리되어 사용성이 크게 향상되었습니다.
  - `admin_base.html`, `admin.css`, `admin.js` 등 새로운 UI 시스템을 위한 기반 파일들이 추가되었습니다.

- **일반 사용자 대시보드 신설**:
  - 관리자가 아닌 일반 사용자를 위한 개인 대시보드가 추가되었습니다.
  - 사용자들은 이제 자신만의 공간에서 논문을 관리하고 개인 Zotero 계정을 연동할 수 있습니다.
  - 로그인 시 사용자의 역할(관리자/일반)에 따라 적절한 대시보드로 리디렉션됩니다.

- **강화된 사용자 관리 (CRUD)**:
  - 관리자는 이제 사용자를 생성, 조회, 수정, 삭제할 수 있는 완전한 CRUD 기능을 갖게 되었습니다.
  - 보안 강화를 위해 비밀번호 복잡성 검사 기능이 도입되었습니다.
  - 모든 사용자 관리 활동은 **감사 로그(Audit Log)**에 기록되어 추적이 가능합니다.

### 2. Zotero 연동 심화

- **향상된 보안**:
  - Zotero API 키는 이제 `Fernet`을 사용하여 암호화된 상태로 데이터베이스에 저장됩니다.
  - 암호화 키는 환경 변수 또는 외부 파일(`refdata/encryption.key`)을 통해 안전하게 관리됩니다.

- **관리자 기능 확장**:
  - 관리자는 이제 각 사용자의 Zotero 설정을 개별적으로 확인하고, 연결 상태를 테스트하며, 동기화를 직접 실행하거나 라이브러리 데이터를 초기화할 수 있습니다.

- **정확한 데이터 모델링**:
  - Zotero의 데이터 구조를 더 정확하게 반영하기 위해 `ZoteroItem`, `ZoteroCollection`, `ZoteroItemPaper` 모델을 새로 도입하여 아이템, 컬렉션, 첨부파일 간의 관계를 명확히 했습니다.

### 3. 백그라운드 작업 및 시스템 관리

- **작업 취소 기능**:
  - 관리자 대시보드에서 실행 중인 백그라운드 작업을 개별적으로 또는 일괄적으로 취소할 수 있는 기능이 추가되었습니다.

- **데이터베이스 초기화 (Danger Zone)**:
  - 관리자가 시스템의 모든 데이터를 안전하게 삭제하고 초기 상태로 되돌릴 수 있는 기능이 추가되었습니다.

### 4. 문서 중복 검사 시스템

- **임베딩 기반 자동 검사**:
  - 문서가 시스템에 추가될 때, 내용(임베딩 벡터)의 유사도를 기반으로 중복 여부를 자동으로 검사합니다.

- **중복 관리 UI**:
  - 관리자는 중복으로 탐지된 문서 쌍을 목록에서 확인하고, "둘 다 유지", "무시", "하나 삭제" 등의 조치를 통해 효율적으로 관리할 수 있습니다.

### 5. 테스트 및 안정성

- **E2E 테스트 환경 구축**:
  - `Playwright`와 `pytest`를 활용한 End-to-End 테스트 환경이 구축되었습니다. 이를 통해 Zotero 연동과 같은 복잡한 사용자 시나리오를 안정적으로 자동 테스트할 수 있습니다.

- **데이터베이스 마이그레이션**:
  - 상기 기능 추가에 필요한 모든 데이터베이스 스키마 변경 사항이 마이그레이션 파일로 생성 및 반영되었습니다.

## 결론

v0.1.5는 RefServerLite가 단순한 문서 저장소에서 **다중 사용자를 지원하는 지능형 연구 문서 관리 플랫폼**으로 도약하는 중요한 마일스톤입니다. 사용자 경험, 보안, 관리 효율성이 모든 면에서 크게 향상되었습니다.
